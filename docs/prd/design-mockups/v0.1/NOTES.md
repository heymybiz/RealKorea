# v0.1 notes

## Palette

| Token | Hex | Use |
|---|---|---|
| Hanji | `#F3EEE4` | Page background |
| Ink | `#161310` | Text |
| Dancheong | `#B33A3A` | Kickers, underline, primary button, verified stamp |
| Rule | `#161310` at 12–20% | Dividers |
| Sage (optional) | `#3D5246` | Rare secondary, never compete with crimson |

Crimson is **≤5% of the frame**. If a screen feels “red”, it is wrong.

## Type

- Display: high-contrast serif (production: Newsreader or Fraunces)
- UI / body: neo-grotesque (production: Geist or Inter)
- Kickers: 11–12px small caps, tracking 0.16em, crimson
- Headlines: tight leading, 3-line max on home hero

## Voice on screen

- Body: Time Out editor — short, sure, unsentimental
- Tip boxes: KakaoTalk-to-a-friend — blunt, specific
- Never tourism-board warmth (“Welcome to beautiful Korea”)

## Do not

- Palace / N Seoul Tower / hanbok as default hero
- Best 50 lists as the product
- Chubby SaaS pills, glassmorphism, Korean flag, gold
- AdSense units in v1
