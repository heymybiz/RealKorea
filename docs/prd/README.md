## Locked product one-liner

Real Korea is an English-language editorial site that answers the *private, practical* questions a foreign visitor would text a Korean friend — not the official brochure — using a Time Out–grade magazine skin over a Q&A-led blog (Tips, Places, Guides).

## Do not build in v1

User accounts, AdSense, a dedicated map product, ranked “Best 50” lists, nightlife as a nav vertical, multi-language UI, booking engines.
