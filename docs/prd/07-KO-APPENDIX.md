## 한 줄 정의

외국인이 한국인 친구에게 카톡으로 물어볼 법한 **사소하고 실질적인 질문**에, 관광청 브로슈어에 없는 답을 주는 **영어 매거진 데스크**.

Time Out처럼 보이고, Time Out처럼 “50선”을 만들지 않습니다. 구조는 **질문 + 짧은 팁 + 장소 카드 + 가이드** 입니다.

| 내비 | F,A,B,C,D | Ask a Local → Tips → Eat & Drink → Places → Shop |

## 신뢰가 이 서비스의 상품

1. 페이지 작성자는 항상 **데스크(에디터)**.  
2. 방문자는 질문하고 댓글 달 수 있다.  
3. 파란 좋아요가 아니라 **붉은 Verified 체크**가 신뢰 표시.  
4. 장소·사실형 팁에는 **Last verified** 날짜.  
5. 돈 되는 링크는 Shop이거나 Partner 배지가 보인다.

이 다섯이 깨지면 Real Korea는 광고 블로그가 됩니다.

## 화면 카피 (한국어 의미, UI는 영어)

| 영어 UI | 의미 |
|---|---|
| Local answers. Not the brochure. | 현지 답. 안내 책자 아님. |
| What locals actually tell friends before you land. | 착륙 전에 친구들이 진짜로 말해 주는 것. |
| Ask something tourists never get a straight answer to | 관광객이 똑바로 못 듣는 질문을 해 보세요. |
| Ask the question you’d text a Korean friend. | 한국인 친구에게 카톡할 그 질문. |
| Editors answer. Good questions become guides. | 에디터가 답하고, 좋은 질문은 가이드가 됩니다. |
| Tips locals send in a group chat. | 단톡에 올라오는 현지 팁. |
| Not a ranking. | 순위표가 아닙니다. |

구현 시 위 영어 문장을 더 부드럽게 바꾸지 마세요. 브랜드 문장입니다.
