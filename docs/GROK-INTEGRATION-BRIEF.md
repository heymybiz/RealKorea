## 3. Strict 3-Role Editorial Production Standard

1. **Role 1 (Fact Gatherer - Grok)**: Domain-locked primary source research (`.go.kr`, `airport.kr`, `t-money.co.kr`, `kakaomobility.com`).
2. **Role 2 (Drafter - Strict Negative Constraints)**:
   - Rule 1: Never guess or invent numbers.
   - Rule 2: Delete unverified claims completely (do not soften).
   - Rule 3: Ban all AI fluff words.
   - Rule 4: Match 100% unique high-res stock photos (1st priority) or photorealistic 16:9 documentary plates (2nd priority).
3. **Role 3 (Auditor & Approver)**: Automated linter scan ➔ Human Editor 3-minute review ➔ 1-click sync (`npm run sync:obsidian`).
