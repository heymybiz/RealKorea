# 발전 방안과 수익화

작성: ReKo 총괄실장 / 2026-08-28 개정

## 지금
정체성: 방한 외국인 × 현지인 여행 꿀팁 (영문).
팀은 레퍼런스·기획·글·자료를 폴더에 쌓는다. 사이트 본체는 별도 공간.

## 담당
- 리서치: 같은 칸의 경쟁·레퍼런스 사이트 조사 분석
- 웹관리: 홈 레퍼런스, 메뉴·카테고리 기획. 신규 구축 안 함
- 작가: 꿀팁을 쓰기 위한 레퍼런스 글
- 자료: 글에 붙일 자료. 공식 문서·지도·간판 위조 금지
- 총괄: 정체성·네이밍·수익화, 출고

## 수익
1차 애드센스. 제휴 메인 금지. 월 10만 목표, 규모 약속 없음.

## 나중에
꿀팁이 쌓인 뒤 일정·다국어. 지금은 열지 않음.
