# Real Korea — site

English-language editorial site for Seoul and the capital region. The product
baseline is **RK-PRD-1.0** in `../docs/prd/`. If this file and the PRD ever
disagree, the PRD wins.

Planning and research documents live in `../Grok-Bot/` and `../docs/`. All
implementation happens in this directory.

## Design system

Tokens live in `src/app/globals.css` and follow PRD 04 §2–4.

```text
paper        #F4EFE6      page background
paper-warm   #EFE6D6      tip box, footer, panels
ink          #161513      body, wordmark
ink-soft     #5C574E      meta
rule         #D9D1C3      hairlines
crimson      #B43A3A      the only accent
```

Display type is Fraunces, body type is Source Sans 3, both self-hosted through
`next/font`. Hangul falls through to a system Korean face rather than a display
font.

Dark mode is out of scope for v1. There is no `.dark` token block, so shadcn's
`dark:` utilities are inert; the `@custom-variant dark` declaration is kept
deliberately, because removing it would hand `dark:` back to the OS media query.

Use `content-shell` for the 1120px measure.

## Content layer

`src/lib/cms.ts` is the only boundary between the site and its content source.
Nothing else may import from `src/lib/content/seed`. Swapping in Sanity means
rewriting the bodies of those accessors and nothing else. Every accessor is
already async for that reason.

Schemas live in `src/lib/content/types.ts` and mirror PRD 03 §3.

Two invariants are enforced rather than documented:

- Visitor emails cannot reach a public surface. `PublicQuestion` and
  `PublicComment` structurally lack the field, and `toPublicQuestion` is an
  explicit allowlist (FR-011, FR-020).
- Sample scaffolding cannot carry a trust signal. `assertSamplesCarryNoTrustSignal`
  runs at module load and fails the build if a sample document sets
  `editorVerified`, `answerVerified`, `lastVerifiedAt`, or a publish date
  (PRD 01 §6).

Seed content is deliberately factless: no fares, hours, routes, coordinates, or
recommendations. Cards render a quiet `Sample` label that disappears once real
editorial content replaces the seed.

## Motion

PRD 04 §6 is the ceiling: 180ms ease-out on hover and buttons, no cover
auto-zoom, checklist checks fade over 120ms, no confetti. `MotionProvider`
sets `reducedMotion="user"`, and `globals.css` also collapses animation for
`prefers-reduced-motion`.

Three animation libraries are installed and available but intentionally unused
in the current build:

```text
src/components/magicui/blur-fade.tsx            Magic UI
src/components/motion-primitives/in-view.tsx    Motion Primitives
src/components/react-bits/blur-text.tsx         React Bits
```

React Bits' `BlurText` on an H1 is held back on purpose: animating the largest
text on the page competes with LCP and CLS (NFR-001, NFR-002). Apply it only on
an explicit decision, then re-measure.

Install further components with the shadcn registry and keep them in their own
directory per source:

```powershell
npx --yes shadcn@4.19.0 add @magicui/marquee --yes
npx --yes shadcn@4.19.0 add "https://motion-primitives.com/c/animated-group.json" --yes
npx --yes shadcn@4.19.0 add "https://reactbits.dev/r/GradientText-TS-TW" --yes
```

If the Motion Primitives registry rate-limits, its own CLI works:

```powershell
npx --yes motion-primitives@0.1.0 add animated-group
```

## Hard rules

Grep-checkable prohibitions from PRD 05 and 06 §0:

```text
no accounts, OAuth, or "Sign in" chrome        FR-023
no adsbygoogle or display ads                  FR-064
no /map route                                  FR-041
no ranked "Best of" content type
no language switcher, English UI only          NFR-015, NFR-016
no "Write a review" CTA on Place
no ShopProduct in a Tip body                   FR-061
```

Copy in PRD 06 §4 and PRD 02 is locked. Do not soften it. Romanization is
`English Name (한글)` on first mention only.
